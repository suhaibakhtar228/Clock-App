# Digital Clock

A simple Digital Clock project made using HTML, CSS and JavaScript.

## Features

- Displays current time and date.
- Stopwatch with Start, Stop and Reset buttons.
- Alarm clock with sound.
- Simple and attractive user interface.

## Technologies Used

- HTML
- CSS
- JavaScript

## Project Files

- `index.html` – Website structure.
- `style.css` – Website design.
- `script.js` – Clock, stopwatch and alarm functions.
- `audiomp3.wav` – Alarm sound.

## How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
4. Set an alarm and test the stopwatch.
